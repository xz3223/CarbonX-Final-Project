How are categories and percentages calculated?

Each percentage is the category count divided by all 1,000 cases, including cases with undefined IRR. Distributions, independence and clipping are illustrative assumptions. These frequencies are not calibrated project success probabilities. Every IRR is calculated using the same cash-flow formulas.
